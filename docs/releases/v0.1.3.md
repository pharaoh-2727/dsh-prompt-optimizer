# v0.1.3

无破坏性改动。升级方式见 [docs/INSTALL.md](https://github.com/pharaoh-2727/dsh-prompt-optimizer/blob/master/docs/INSTALL.md)，
装法 A/B/C 都适用，覆盖文件后重启 DSH 即可。

## 修复

- **短到没有内容可补的输入原样返回**：像「改」这样的一个字的输入，以前会被补成一百多字的空话，现在原样还给你，也不再等模型
- **接着上文说的话会被当成任务**：「继续」「重来」「这个不对」以前被当成闲聊，一个字都不改；现在会交给模型接着上文补
- **带文件的提问不再被补成任务**：「src/app.ts 为什么这么慢？」「package.json 里的 scripts 是干嘛的？」以前会被当成任务补上「目标 / 步骤 / 产出 / 验收」，现在保持提问
- **「别用 any」「加一个超时」这类一句话的任务会被补清楚**：补的是「在哪儿」「给谁」，不再原样返回
- **长文本的上限不再低于原文**：五千字的输入以前上限只有四千，等于要求把长文压成短文；现在上限至少等于原文
- **优化不会再等两分钟**：模型慢的时候以前会连着补救两三轮，现在有总时间预算，来不及就先把结果给你
- **思考过程不会再挤掉正文**：模型的思考会占满输出额度，极端情况下正文是空的却显示「优化完成」；现在给思考留足了空间

## 改动

- 提示词补了英文输入的写法：英文同样要补出 Goal / Steps / Output / Acceptance，不再只加一个「Goal:」前缀
- 已经通顺的「好的，谢谢」这类不再被改动标点
