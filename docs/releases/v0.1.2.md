# v0.1.2

升级方式见 [docs/INSTALL.md](https://github.com/pharaoh-2727/dsh-prompt-optimizer/blob/master/docs/INSTALL.md)。
装法 A/B/C 都适用，覆盖文件后重启 DSH 即可。

## 修复

- **提问不再被补成任务**：问句只会被改写成更清楚的问句，不再被补上「目标 / 步骤 / 产出格式」。
  引擎判断输入性质时改为看有没有指向工作区的信号（路径、文件名、命令、报错原文），
  不再按关键词表判断
- **结果框里不再出现思考过程**：模型把推理写进正文时会被剥掉；
  思考块默认收起成一行「思考过程 · N 字」，点标题展开
- **点「放弃」之后，结果不会再自己弹回来**
- **预览卡只留在发起它的那个对话**，切到别的对话不再串显示

## 改动

- 均衡档删掉「自检」一段 —— 它要求模型回看原文判断有没有漏掉交付意图，模型做不到

## 测试

新增 `dev/test-input-kind.cjs`（36 条判据语料 + 6 条端到端用例）和
`dev/test-dock-behaviour.cjs`（5 条用例）。测试套数 12 → 14。

```bash
npm test    # 14 套，约 11 秒，不需要 DSH 在跑
```

## 兼容性

无破坏性改动。六个入口、配置项、`localStorage` 键名、HTTP 路由都没动。
