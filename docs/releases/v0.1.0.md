# v0.1.0

首个公开版本。功能与交互已稳定，插件在 DeepSeek Harness `0.2.1-rc.5` 上实测可用。

升级方式见 [docs/INSTALL.md](https://github.com/pharaoh-2727/dsh-prompt-optimizer/blob/master/docs/INSTALL.md)。

## 功能

- **六个入口，同一份实现**：输入框按钮、会话标题旁按钮、`Alt+O` 快捷键、
  `/optimize` 斜杠命令、`optimize_prompt` 工具、`promptOptimizer` 服务
- **预览卡确认流程**：结果不直接覆盖草稿，点「替换草稿」才写回；写回后按钮变「退回」，可一键还原
- **流式生成**：SSE 边收边显示，思考过程与正文分开展示；流式不可用时自动退回一次性接口
- **历史版本与逐行对比**：每次成功留一版（最多 20 条），可回看、可并排对比、可删除清空
- **对比原文**：逐行标出优化到底改了哪些字
- **整张预览卡可缩放**：高度与宽度都能拖，支持键盘微调，尺寸记在 localStorage
- **三档力度**：精简 / 均衡 / 详细，各有独立的长度上限、允许项与禁止项，另有自定义档
- **档位复核**：模型超长就带修正指令重试、过短就补写重试，重试始终用用户选的档位
- **失控兜底**：短输入被扩成文档时自动改用精简档
- **编辑冲突保护**：等待期间改了输入框，结果不会覆盖新内容，「替换草稿」自动禁用
- **取消**：优化中可中止，底层网络请求真断开，不弹红色错误
- **免费通道**（可选）：OpenAI 兼容端点，失败按 `auth` / `rate` / `server` / `timeout` / `network` 分类，
  `auth` 判定为死之后不再反复请求；不可用时自动回退到当前对话模型
- **零配置**：「自动」模式跟随当前对话正在用的模型，永远可用
- **设置页**：力度、模型三选一、免费通道连通性测试、上次实际调用

## 与上游 `dsh-prompt-enhancer` 的差异

架构、交互、配置与上游一致，差异只在改写规则：

- 场景约定换成 DeepSeek Harness 的真实用法：`@` 文件引用语法、工作区相对路径、
  read/write/edit/glob/grep/bash/pwsh 工具面、可判定的验收口径、Windows + PowerShell 环境
- 任务关键词表按 DSH 场景补齐

## 安全

- **源码中不含任何凭据**。免费通道密钥只从环境变量 `DSH_FREE_CHANNEL_API_KEY` 读取；
  未配置时跳过该路径，不报错、不影响主流程
- 免费通道端点与模型名有公开默认值，可用 `DSH_FREE_CHANNEL_BASE_URL` / `_MODEL` 覆盖

## 已知限制

- 「自动」模式依赖宿主能解析出一个模型；解析不到时需要在设置里手动指定（见 docs/INSTALL.md 排错）
- 历史版本存在浏览器 localStorage，**不跨设备、不跨浏览器**；写不进去时只在本次会话内有效
- 输入单次上限 20000 字符
