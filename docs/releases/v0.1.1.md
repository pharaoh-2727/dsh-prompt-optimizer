# v0.1.1

升级方式见 [docs/INSTALL.md](https://github.com/pharaoh-2727/dsh-prompt-optimizer/blob/master/docs/INSTALL.md)。
装法 A/B/C 都适用，覆盖文件后重启 DSH 即可。

## 修复

- **换稿时会先说清原因**：补救重写开始前先推一条 `revise` 事件，预览卡标题行显示
  「正在重新收敛…」这类说明，不再出现「字长到一半停住、等几秒、整段换成另一份」
- **上一批事件迟到时不再覆盖新一次优化**
- **正在生成时点「优化」会真的再开一次**，而不是被静默忽略
- **回执里的 provider / model 取自真正产出这份正文的那一轮**

## 测试

新增 `dev/test-result-stability.cjs`，钉住两条不变量：最后一帧 `delta` 等于 `done.text`；
正文与流下来的那版不同时，流里必先有 `revise` 且带原因。测试套数 8 → 9。

```bash
npm test    # 9 套，约 5 秒，不需要 DSH 在跑
```

## 兼容性

无破坏性改动。`revise` 是新增事件：旧客户端不认识会忽略掉，结果照样对，
只是不显示换稿原因；新客户端连老宿主也不会出问题，没有 `revise` 时标题行保持「生成中…」。
宿主侧 `promptOptimizer` 服务的接口版本仍是 `version: 1`。
