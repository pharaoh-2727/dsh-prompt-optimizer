# v0.1.4

无破坏性改动。升级方式见 [docs/INSTALL.md](https://github.com/pharaoh-2727/dsh-prompt-optimizer/blob/master/docs/INSTALL.md)，
装法 A/B/C 都适用，覆盖文件后重启 DSH 即可。

## 新增

- **我的偏好**：把「每次都在改同一件事」攒成几条固定规则（「不要用 emoji」「产出用编号列表」），
  以后每次优化都照做，三档都生效。在「设置 → 优化 → 我的偏好」里加，回车即可。
- **失败时给备选**：优化失败不再只显示一句红字，而是给出「下一步能点什么」——
  没配模型时给「去选模型」，原文太长时给「精简原文」和「换精简档」，
  模型没返回内容时给「再试一次」。只给真的能做的：没配模型时不给「重试」
  （重试还是同一个错），原文太长时不给「去选模型」（跟模型无关）。

## 修复

- **失败时点「去选模型」不再跳到空白页**：以前会跳到一个不存在的地址。
  现在直接打开设置面板；万一找不到设置入口，会把该去哪儿写在那行提示里。
