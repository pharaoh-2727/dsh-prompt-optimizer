# v0.1.5

无破坏性改动。升级方式见 [docs/INSTALL.md](https://github.com/pharaoh-2727/dsh-prompt-optimizer/blob/master/docs/INSTALL.md)，
装法 A/B/C 都适用，覆盖文件后重启 DSH 即可。

## 修复

- **设置页又能打开了**：从 v0.1.4 起，点「优化 → 设置」只会看到一行
  「优化设置加载出错，请刷新页面重试。」，刷新也没用。原因是那次加「我的偏好」时，
  两个 React hook 被写在了「设置还没读回来就先返回」的分支后面：第一次渲染只跑 10 个，
  设置读回来变成 12 个，React 直接报 `Rendered more hooks than during the previous render`，
  错误边界接住之后整页就只剩那行红字。现在把这两个 hook 挪到提前返回之前。
  你的偏好、模型、力度这些设置一直都好好存着，只是页面画不出来，升级后不会丢。
- **适配 DSH 0.2.2**：「优化器跟随当前会话的模型」本来记模型的入口已经被上游标为弃用，
  而且新的校验会让旧的写法直接抛错。已改到现行入口，同时修好了一处会话 id 对不上导致的
  静默失效 —— 以前它看起来是通的，其实一直没跟上模型。
- **取会话改用现行 API**：原来那条路在当前宿主里不存在，属于死分支。现在取不到会逐级退，
  都没有就不给值，不再凭空编一个工作目录出来。

## 新增

- **插件页有图标和标题了**：以前只有一张默认图，标题和描述也是空的。
- **三套防回归测试**：盯着 DSH 兼容性、manifest 导出，以及上面那个 hook 顺序问题 ——
  最后这套用修复前的代码跑会红，报的就是真机上那句错。
